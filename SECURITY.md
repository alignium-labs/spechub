# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Email [security@spechub.ai](mailto:security@spechub.ai) with:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- Any relevant screenshots, logs, or supporting material

We will acknowledge your report promptly and keep you informed as we investigate and resolve the issue.

For more information on how we protect your data, see our [Security page](https://spechub.ai/security).
