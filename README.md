# SpecHub

[SpecHub](https://spechub.ai) is an AI-powered software planning platform that helps teams collaboratively create clear, structured, and aligned specifications — and hand them off to coding agents with confidence.

This repository is the public issue tracker for SpecHub.

## Reporting a Bug

[Open a bug report](../../issues/new?template=bug_report.yml) and include as much detail as you can — steps to reproduce, what you expected, and what actually happened. Clear reports get resolved faster.

## Requesting a Feature

[Open a feature request](../../issues/new?template=feature_request.yml) and describe the problem you are trying to solve. Approved requests are published on our public roadmap.

## Before You Open an Issue

- **Search existing issues** — your bug or idea may already be tracked
- **Security vulnerabilities** — do not file publicly; see [SECURITY.md](SECURITY.md)
- **Billing and account questions** — contact [support@spechub.ai](mailto:support@spechub.ai)
